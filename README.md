# BattleDex Discord bot
Unlike other dexes, this one does not spawn balls or anything like that. Rather, it allows players to have a more engaging fight with the balls they have obtained from Ballsdex, by recognising the type of ball through info cards, and adding the buff stats to that. 
UNDER CONSTRUCTION: This bot is far from complete, and a work in progress. If you encounter any bugs, make sure to DM on discord sky.05 or thedarkdiamond24. 
Abilities do not yet work, but we hope to be able to get them to work in the future.
